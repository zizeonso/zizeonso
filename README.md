### About

I'm interested in clean, reproducible tools for scientific data, machine learning,
remote-sensing imagery, and data-centric AI. My work usually sits somewhere
between physical intuition, Python-heavy analysis, and model-building.

I like projects that turn complicated data into something easier to inspect,
test, and explain.
